InstaCheckListで利用するGoogleユーザーデータ、カメラおよびブラウザ内データの取り扱いを説明します。

最終更新日：2026年8月10日

取得・利用するGoogleユーザーデータ

利用者がGoogleアカウント連携を選択した場合、Google Pickerで利用者自身が選択したSpreadsheet、アプリが作成したSpreadsheet、または共有URLで指定され利用者に共有済みのSpreadsheetの内容と、Googleプロフィールの表示名を取得します。Spreadsheetの作業項目を表示し、シリアル番号ごとの完了日時、作業者名、固有値および作業メモを保存する目的にのみ使用します。

要求する権限は、作業写真などアプリが扱うDriveファイルのファイル単位権限（drive.file）、対象Spreadsheetを読み書きする権限（spreadsheets）、作業者名を表示・記録する基本プロフィール権限（userinfo.profile）です。共有URLにはSpreadsheet IDだけを含み、Googleの共有設定で権限を持たないアカウントはアクセスできません。本アプリは共有URLで指定された対象以外のSpreadsheetを検索・一覧取得しません。

Google Spreadsheetの作成と保存

「新しいチェックシートを作成」を選択した場合、利用者のGoogle DriveにInstaCheckList用Spreadsheetを新規作成し、指定されたタイトル行を設定します。既存ファイルはGoogle Pickerで利用者が選択するか、対象Spreadsheet IDを含む共有URLから開きます。

作業項目には行番号の変更に対応する識別IDを付与し、対象Spreadsheet内の非表示履歴シートへチェック記録を保存します。複数ユーザーが同じSpreadsheetを編集するため、保存の前後に最新データを再取得します。本アプリは利用者が選択、作成、または共有URLで指定したファイルを作業対象とし、それ以外のSpreadsheetを検索・一覧取得しません。

データの保管と共有

Googleから取得したデータとOAuthアクセストークンは利用者のブラウザとGoogleのサービス間で処理し、SONA CRAFTが運営する独自サーバーへ送信・保存しません。作業記録は利用者が選択したSpreadsheetに保存され、その共有設定に従って共同編集者へ共有されます。

Googleユーザーデータを広告、信用評価、販売、または利用者へ明示した機能と無関係な目的に使用せず、法令上必要な場合を除いて第三者へ提供しません。人によるGoogleユーザーデータの閲覧も行いません。

ブラウザに保存する情報

前回選択したSpreadsheetのファイルIDをブラウザのローカルストレージへ保存します。OAuthアクセストークンはメモリ内でのみ保持し、ページを閉じると破棄されます。ブラウザのサイトデータを削除すると、保存したファイルIDも削除されます。

カメラと作業写真

シリアル番号のバーコードまたはQRコードを読み取るため、利用者が許可した場合に端末のカメラを使用します。コード読取中の映像はブラウザ内で解析し、録画または保存しません。利用者が項目のカメラボタンとシャッターボタンを操作して撮影した作業写真だけを、利用者のGoogle Driveへ保存します。写真のDriveリンク、ファイルID、撮影日時、作業者名、対象シリアル番号および項目IDは、選択中のSpreadsheet内の非表示シート「_InstaCheckList_Photos」へ記録します。本アプリ独自のサーバーには送信・保存しません。

アクセス権の取り消しとデータ削除

Googleアカウントの「サードパーティ製のアプリとサービス」設定から、いつでもInstaCheckListのアクセス権を取り消せます。作業記録を削除する場合は、対象Spreadsheetの「_InstaCheckList_Log」シートを再表示して該当行を削除してください。ブラウザ内の設定はサイトデータの削除により消去できます。

Google API Services User Data Policy

本アプリによるGoogle APIから受け取った情報の利用および他のアプリへの転送は、限定使用要件を含むGoogle API Services User Data Policyに従います。
